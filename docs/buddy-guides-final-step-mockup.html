⌘Buddy Guides At A Glance

Guide 01

Start with the job

Say what you want done first: rewrite, summarize, extract, brainstorm, explain.

Guide 02

Add context when it matters

Mention audience, tone, length, or whether selected text should be used as source material.

Guide 03

Ask for the shape you want

People learn faster when the examples ask for bullets, plain English, a draft reply, or key takeaways.
