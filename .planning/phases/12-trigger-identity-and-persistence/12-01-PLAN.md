<interfaces>
New persistence surface should stay aligned with existing app-state patterns:

```swift
struct TriggerProfile: Equatable, Codable {
    var activeProfile: TriggerNamePreset
    var customPrimary: String
    var customAliases: [String]
}
```

```swift
actor TriggerProfileStore {
    func load() async -> TriggerProfile
    func save(_ profile: TriggerProfile) async throws
}
```

```swift
@MainActor
final class ShellPreferences: ObservableObject {
    @Published private(set) var activeTriggerProfile: TriggerProfile
    func setTriggerPreset(_ preset: TriggerNamePreset)
    func setCustomTrigger(primary: String, aliases: [String])
}
```

Implementation must preserve current convert-mode persistence contracts and keep trigger updates immediately visible for next-session runtime behavior.
</interfaces>
