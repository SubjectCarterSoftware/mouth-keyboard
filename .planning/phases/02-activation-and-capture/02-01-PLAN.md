       Define the shortcut name at file scope:
       ```swift
       import KeyboardShortcuts
       extension KeyboardShortcuts.Name {
           static let activate = Self("activate", default: .init(.z, modifiers: [.command, .shift]))
       }
       ```

       Implement HotkeyService as a class (not actor — CGEventTap C callback requires careful threading):
       - Properties: tapMode (read from ShellPreferences.shared), doubleTapWindow: CFAbsoluteTime = 0.350
       - Injectable clock: var now: () -> CFAbsoluteTime = CFAbsoluteTimeGetCurrent (swap in tests)
       - Injectable arm callback: var onArm: () -> Void (calls ActivationStore.shared.arm() in production)
       - Private: lastTapTime, pendingTapWork: DispatchWorkItem?

       func handleKeyDown() -> Bool — pure logic, no CGEvent parameter needed for testability:
         - Implements double-tap / single-tap logic per research Pattern 2
         - doubleTapWindow: 350ms fixed
         - Returns true (event consumed) always (prevents system beep)

       func start() — installs CGEventTap:
         - Guard CGPreflightListenEventAccess() else log and return
         - Create tap monitoring keyDown events only
         - C callback dispatches to handleKeyDown() on main queue
         - Handle kCGEventTapDisabledByTimeout: call CGEvent.tapEnable(tap:enable:true) immediately
         - Use Unmanaged.passRetained(self) for userInfo; release in stop()
         - Run loop source added to CFRunLoopGetMain()

       func stop() — removes tap, releases Unmanaged pointer

       In production (AppDelegate or application init), HotkeyService.shared.start() is called
       after ReadinessStore confirms .ready. For Phase 2, start it unconditionally at app launch
       if AXIsProcessTrusted() — Plan 03 will refine the readiness gate.

       Anti-patterns to avoid (per research):
       - Do NOT use NSEvent.addGlobalMonitorForEvents (cannot consume events)
       - Do NOT do blocking work inside CGEventTap callback
       - Always handle kCGEventTapDisabledByTimeout
