         - Compute RMS via vDSP_rmsqv on first channel (import Accelerate)

    3. Create Speech2Test/Audio/AudioCaptureService.swift:
       - final class AudioCaptureService (not @MainActor — audio callbacks are off main thread)
       - private let engine = AVAudioEngine()
       - private var levelMonitor: AudioLevelMonitor?

       func prepare() throws:
         - engine.prepare() — pre-allocates resources so start() is fast (ACTV-04)
         - Call this once at app launch from AppDelegate after mic permission confirmed ready

       func start(levelMonitor: AudioLevelMonitor) throws:
         - Guard engine is not already running
         - self.levelMonitor = levelMonitor
         - let inputNode = engine.inputNode
         - let format = inputNode.outputFormat(forBus: 0)   // MUST match installed format
         - inputNode.installTap(onBus: 0, bufferSize: 4096, format: format) { [weak self] buffer, _ in
               self?.levelMonitor?.process(buffer: buffer)
           }
         - Do NOT connect inputNode to engine.mainMixerNode or outputNode (AUDI-03)
         - try engine.start()

       func stop():
         - engine.inputNode.removeTap(onBus: 0)
         - engine.stop()
         - levelMonitor = nil

       Important pitfall avoidance (from research):
       - format must come from inputNode.outputFormat(forBus: 0) — never hardcoded
       - Tap is on inputNode only — never add connections to outputNode
       - engine.prepare() is called in prepare(), NOT inside start() (ACTV-04 latency)

  <action>
    1. Create Speech2Test/Audio/AudioDeviceService.swift:
       - import CoreAudio, AVFoundation

       struct AudioInputDevice: Identifiable {
           let id: AudioDeviceID
           let name: String
           let uid: String
       }

       @MainActor final class AudioDeviceService: ObservableObject {
           static let shared = AudioDeviceService()
           @Published private(set) var availableDevices: [AudioInputDevice] = []

           func refresh():
             - Use AudioObjectGetPropertyData with kAudioHardwarePropertyDevices to get all device IDs
             - For each device ID, check kAudioDevicePropertyStreams on kAudioDevicePropertyScopeInput
               to confirm it has input channels (filters out output-only devices)
             - Get device name via kAudioObjectPropertyName
             - Get device UID via kAudioDevicePropertyDeviceUID
             - Filter out any device with 0 input channels
             - Assign result to availableDevices (no "System Default" entry — that is UI-only)
             - Pattern from research Pattern 4 — use exactly the CoreAudio enumeration shown there

           func setInputDevice(_ device: AudioInputDevice?, on engine: AVAudioEngine) throws:
             - If device is nil: return immediately (engine uses system default — no AudioUnitSetProperty call)
             - Otherwise: call AudioUnitSetProperty with kAudioOutputUnitProperty_CurrentDevice
               on engine.inputNode.audioUnit! as shown in research Pattern 4
             - Throws NSError if AudioUnitSetProperty returns non-noErr status
             - CRITICAL: Must only be called before engine.start() — caller's responsibility

           func registerDisconnectListener(for deviceUID: String, onDisconnect: @escaping () -> Void):
             - Find the AudioDeviceID for the given UID
             - Register kAudioDevicePropertyDeviceIsAlive property listener via
               AudioObjectAddPropertyListener
             - When listener fires with alive=false: call onDisconnect() on main queue
             - AudioCaptureService uses this to fall back to system default silently (Plan 03 wiring)
       }
