<decisions_made>

- **SpacebarInterceptor removed**: CGEventTap requires Accessibility permission — extra friction not worth it. Ctrl+V now toggles both start and finish via arm() toggle behavior in ActivationStore.
- **Buffer reset moved to arm()**: AudioCaptureService.stop() should NOT reset the accumulator it doesn't own. ActivationStore resets it at start of each new recording.
- **whisper.spm at branch: master**: Required to avoid unsafe build flag errors. Exact URL: https://github.com/ggerganov/whisper.spm
- **Model not in Xcode project**: ggml-small.en.bin is too large for git (465MB). Manual copy to DerivedData bundle required after each clean build. User needs to add to Xcode project manually (drag into navigator, check "Add to target").
- **removeDuplicates() removed from state pipeline**: Terminal states are always distinct, need observation.
- **WhisperService.shared singleton**: AppDelegate and ActivationStore.shared share one model instance.

</decisions_made>
