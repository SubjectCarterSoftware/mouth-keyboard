  <action>
    **RecordingPillView.swift — Multi-state rendering:**

    Change the view to accept `RecordingState` (observed from ActivationStore) in addition to `AudioLevelMonitor`:
    - Add `let recordingState: RecordingState` property
    - Add `@State private var silenceWarningActive: Bool = false` for 45s visual warning

    Replace the body with a switch on recordingState:

    `case .recording`:
    - Existing waveform bar visualization (preserve current code)
    - When `silenceWarningActive` is true, tint the bars or background with a subtle amber/orange shift to warn the user that silence timeout is approaching
    - Mic icon + waveform bars layout unchanged

    `case .processing`:
    - Replace waveform with a **pulsing animation**: 3 dots or a simple circle that pulses opacity from 0.3 to 1.0 with a repeating easeInOut animation (~0.8s per cycle)
    - Show "Processing..." text or just the pulsing visual (per user decision: "No text change, no spinner" — use pulsing dots/circle only)
    - Keep the same pill width (160pt) for visual consistency
    - Use `.opacity` modifier with `.animation(.easeInOut(duration: 0.8).repeatForever(autoreverses: true))`

    `case .success`:
    - Show checkmark icon (SF Symbol "checkmark.circle.fill") in green/white
    - Show "Copied!" text next to the checkmark
    - Brief flash effect: start at full opacity, the auto-dismiss is handled by state machine (1.5s timeout in ActivationStore)

    `case .failure(let reason)`:
    - Background tint shifts to red (use `.background(Color.red.opacity(0.8))` on the pill content)
    - Show exclamation icon (SF Symbol "exclamationmark.triangle.fill")
    - Show failure message text based on reason:
      - `.noSpeechDetected` -> "No speech detected"
      - `.modelError(let msg)` -> "Model error" (truncate msg for display)
      - `.silenceTimeout` -> "Silence timeout"
    - Pill may need to be wider for failure text — the panel will handle dynamic sizing

    `case .idle`:
    - Return EmptyView (pill should be hidden at this point anyway)

    Add a method `func setSilenceWarning(_ active: Bool)` or use a binding/callback for the 45s warning visual.

    **RecordingPillPanel.swift — Dynamic sizing and visibility:**

    Change `panelSize` from a constant to a computed or variable property:
    - Recording/processing: 160x44 (current size)
    - Success: 160x44 (same)
    - Failure: 220x44 (wider for failure message text)

    Add a method `func updateForState(_ state: RecordingState)`:
    - Compute appropriate size based on state
    - Call `setFrame(...)` with animated transition if size changes
    - Call `updatePosition()` to re-center

    Update the `init` to accept `ActivationStore` (or just pass `RecordingState` as a binding) so the pill view can observe state changes. The hosting view needs to be recreated or the view needs to observe the state.

    Approach: Pass `activationStore` to `RecordingPillPanel`. The panel creates the hosting view with `RecordingPillView(levelMonitor:recordingState:)`. Since `ActivationStore` is `@ObservableObject`, the SwiftUI view will reactively update.

    **StatusMenuView.swift — Indicator visibility toggle:**

    Add a Toggle for indicator visibility:
    ```swift
    Toggle("Show recording indicator", isOn: $preferences.indicatorVisible)
    ```
    Place it alongside existing toggles (activation sound, etc.).
