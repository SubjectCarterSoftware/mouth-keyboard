Output: Modified ActivationStore (finish flow), AudioCaptureService (buffer accumulation), AudioLevelMonitor (silence detection), AppDelegate (state wiring + spacebar lifecycle), expanded ActivationStoreTests.

  <behavior>
    ActivationStore finish flow:
    - finish() transitions state from .recording to .processing
    - finish() does NOT transition if state is not .recording (no-op)
    - After transcription succeeds: state becomes .success(text:) then auto-transitions to .idle after ~1.5s
    - After transcription fails (noSpeechDetected): state becomes .failure(reason: .noSpeechDetected) then auto-transitions to .idle after ~2s
    - After transcription fails (silenceTimeout): state becomes .failure(reason: .silenceTimeout)
    - Successful transcription calls clipboardService.writeToClipboard with the text
    - When autoPasteEnabled is true, clipboardService.autoPaste() is called after clipboard write
    - When autoPasteEnabled is false, autoPaste is NOT called
    - On failure, clipboard is NOT written to (left unchanged)
    - arm() while in .recording state calls finish() (toggle behavior becomes finish, not just stop)

    AudioCaptureService buffer accumulation:
    - start() now accepts an optional AudioBufferAccumulator parameter
    - The tap callback calls accumulator.append(buffer) in addition to levelMonitor.process(buffer:)
    - stop() resets the accumulator
    - getAccumulatedSamples() returns accumulator.convertToWhisperFormat()

    AudioLevelMonitor silence detection:
    - Track consecutive silence duration (level below threshold for consecutive process() calls)
    - Silence threshold: normalized level < 0.01 (effectively -60dB)
    - onSilenceWarning callback fires at ~45s of continuous silence
    - onSilenceTimeout callback fires at ~60s of continuous silence
    - Any non-silent buffer resets the silence counter
    - reset() clears silence tracking state
  </behavior>
  <action>
    **ActivationStore.swift — Major expansion:**

    Add dependencies via init:
    - `whisperService: any WhisperTranscribing` (default: `WhisperService()`)
    - `clipboardService: ClipboardService` (default: `.init()`)
    - `bufferAccumulator: AudioBufferAccumulator` (default: `.init()`)

    Add `func finish()`:
    1. Guard `state == .recording`, else return
    2. Set `state = .processing`
    3. Spawn a `Task` that:
       a. Calls `let samples = try bufferAccumulator.convertToWhisperFormat()`
       b. Calls `let text = try await whisperService.transcribe(samples: samples)`
       c. On success: `state = .success(text: text)`, call `clipboardService.writeToClipboard(text)`, if `preferences.autoPasteEnabled` call `clipboardService.autoPaste()`
       d. On catch `TranscriptionError.noSpeechDetected`: `state = .failure(reason: .noSpeechDetected)`
       e. On catch other: `state = .failure(reason: .modelError(error.localizedDescription))`
       f. After success/failure: schedule `Task` with sleep to transition to `.idle` (1.5s for success, 2s for failure)

    Modify `arm()`: When state is `.recording`, call `finish()` instead of `stop()`. This changes toggle from stop-to-idle to finish-and-transcribe. Keep `stop()` as a hard-stop (used for cancel in Phase 4).

    Add `func handleSilenceTimeout()`: Sets `state = .failure(reason: .silenceTimeout)`, or calls `finish()` to attempt transcription of whatever was captured. Per user decision: "Still attempt transcription on whatever audio was captured" — so call `finish()`.

    Update the shared singleton to inject real services. Keep init flexible for testing with protocol-based dependencies.

    **AudioCaptureService.swift — Buffer accumulation:**

    Add optional `private var bufferAccumulator: AudioBufferAccumulator?`

    Modify `start(levelMonitor:)` to also accept `bufferAccumulator: AudioBufferAccumulator? = nil`. Store the reference. In the tap callback (line 153), add `self?.bufferAccumulator?.append(buffer)` alongside the existing `levelMonitor.process(buffer:)`.

    Modify `stop()`: call `bufferAccumulator?.reset()`, set to nil.

    **AudioLevelMonitor.swift — Silence detection:**

    Add private properties:
    - `private var silenceStartTime: Date?`
    - `private let silenceThreshold: Float = 0.01`
    - `private var hasFiredWarning = false`
    - `private var hasFiredTimeout = false`
    - `var onSilenceWarning: (() -> Void)?`
    - `var onSilenceTimeout: (() -> Void)?`

    In the `Task { @MainActor in ... }` block after computing normalized level:
    - If normalized < silenceThreshold: if silenceStartTime is nil, set it to Date()
    - Compute elapsed = Date().timeIntervalSince(silenceStartTime!)
    - If elapsed >= 45 and !hasFiredWarning: fire onSilenceWarning, set hasFiredWarning = true
    - If elapsed >= 60 and !hasFiredTimeout: fire onSilenceTimeout, set hasFiredTimeout = true
    - If normalized >= silenceThreshold: reset silenceStartTime to nil, hasFiredWarning/hasFiredTimeout to false

    In `reset()`: clear silenceStartTime, hasFiredWarning, hasFiredTimeout.

    Create a `MockWhisperTranscriber: WhisperTranscribing` that returns configurable results.
    Create a `MockClipboardService` subclass or protocol mock.

    Add tests:
    - test_finish_transitions_to_processing: arm(), verify .recording, finish(), verify .processing
    - test_finish_succeeds_writes_clipboard: mock transcriber returns "Hello world", verify clipboard written
    - test_finish_fails_no_speech: mock transcriber throws noSpeechDetected, verify .failure(.noSpeechDetected)
    - test_finish_no_op_when_not_recording: finish() from idle does nothing
    - test_arm_while_recording_calls_finish: arm() then arm() again triggers finish flow
    - test_auto_paste_enabled: verify autoPaste called when preference is true
    - test_auto_paste_disabled: verify autoPaste NOT called when preference is false
    - test_failure_does_not_write_clipboard: on transcription failure, clipboard write is not called
