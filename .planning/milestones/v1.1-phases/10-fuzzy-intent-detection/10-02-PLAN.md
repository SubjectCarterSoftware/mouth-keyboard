Normalization pipeline (from RESEARCH.md — apply in this order):
1. Lowercase
2. Collapse whitespace (split on .whitespacesAndNewlines, filter empty, rejoin with " ")
3. Strip terminal punctuation (. , ! ?) from trailing end
4. Canonicalize variants: "e mail"→"email", "action item"→"action items", "a i prompt"→"ai prompt", "a.i. prompt"→"ai prompt", "slack message"→"slack", "teams message"→"teams"

Zone extraction (applied to the normalized full transcript):
- Window size: 10 tokens
- Leading zone: tokens.prefix(10).joined(separator: " ")
- Trailing zone: tokens.suffix(10).joined(separator: " ")
- If transcript < 10 tokens: both zones equal the full normalized transcript

Filler stripping (applied to zone candidates only, NOT full transcript):
- Prefix fillers to strip: "can you ", "real quick ", "okay ", "please ", "uh ", "um ", "so ", "alright ", "hey "
- Suffix fillers to strip: " please", " real quick", " okay", " uh", " um", " so", " alright"
- Apply iteratively (multiple fillers may stack)

Composite scoring per (intent, zone):
1. Exact match: if fillerStripped(zone) contains pattern as substring → score = 1.0, stop
2. Fuzzy: max(jaroWinkler(fillerStripped(zone), pattern) for pattern in phrasePatterns)
3. Keyword bonus: if fillerStripped(zone) contains intent.keywordSignal → add 0.15 (cap at 1.0)
4. Composite = max(exactScore, fuzzyScore) + keywordBonus

Auto-trigger conditions (per transcript):
- bestScore >= intent.confidenceThreshold
- bestScore - secondBestScore >= 0.15 (minimum margin)
- If both conditions met: winning intent triggers

Trailing-wins rule:
- Collect trailing result first, then leading
- If trailing zone produces a winner → use it (ignore leading)
- If trailing zone has no winner but leading zone does → use leading
- If trailing wins: apply stripLeadingTriggerIfPresent to strippedBody (remove any residual leading command pattern)

Span removal:
- Identify which zone (leading or trailing) produced the winning match
- Find the matched pattern in the ORIGINAL (pre-normalization) transcript using case-insensitive range search
- Remove matched range + surrounding whitespace from original
- strippedBody = result, trimmed
- originalTranscript = raw input, always unmodified

Jaro-Winkler reference formula (from RESEARCH.md):
- Match distance = max(len_s, len_t) / 2 - 1
- Count matching characters within match distance
- Count transpositions
- Jaro = (matches/len_s + matches/len_t + (matches - transpositions/2) / matches) / 3
- Prefix length: count matching prefix chars, max 4
- Winkler = Jaro + prefixLen * 0.1 * (1 - Jaro)
- Special cases: identical strings → 1.0, either empty → 0.0, no matches → 0.0

Implementation structure:

```swift
enum IntentDetector {
    static let commandWindowTokens = 10
    static let minimumMargin = 0.15

    static func detect(transcript: String, modes: [ConvertMode]) -> ConvertIntent { ... }

    // Normalization (applied to full transcript and zones)
    private static func normalize(_ s: String) -> String { ... }

    // Zone extraction from a normalized transcript
    private static func extractZones(from normalized: String) -> (leading: String, trailing: String) { ... }

    // Filler stripping (zone-only, not full body)
    private static func stripFillers(_ zone: String) -> String { ... }

    // Composite scoring: returns best (definition, score) for a given zone
    private static func score(zone: String, against definitions: [IntentDefinition]) -> (definition: IntentDefinition, score: Double)? { ... }

    // Body extraction from original transcript given the matched zone (leading or trailing)
    private static func extractBody(from original: String, matchedZone: ZoneMatch) -> String { ... }

    // Strip any residual leading trigger from trailing-match body (preserved from Phase 7)
    private static func stripLeadingTriggerIfPresent(from body: String) -> String { ... }
}

private enum ZoneMatch {
    case leading(matchedPattern: String)
    case trailing(matchedPattern: String)
}
```

Key implementation details:

**normalize(_:)**: implement in this exact order: lowercase → collapse whitespace → strip terminal punctuation (loop while last char is in [".","!","?",","]) → apply canonicalization substitutions from RESEARCH.md ("e mail"→"email", "action item "→"action items ", "action item" terminal→"action items", "a i prompt"→"ai prompt", "a.i. prompt"→"ai prompt", "slack message"→"slack", "teams message"→"teams").

**extractZones(from:)**: split on " ", prefix/suffix by min(commandWindowTokens, count), join. If transcript has 0 tokens, return ("", "").

**stripFillers(_:)**: iterate prefix fillers in order, strip if present, repeat until stable. Same for suffix fillers. Trim whitespace. Apply iteratively to handle stacked fillers ("um can you ..." → strip "um " → "can you ..." → strip "can you " → ...).

**score(zone:against:)**:
1. Apply stripFillers to zone → candidate
2. For each definition in definitions (skip .passthrough):
   a. Exact match: if candidate.contains(pattern) for any pattern → score = 1.0, record matchedPattern
   b. Fuzzy: for each pattern, compute jaroWinkler(candidate, pattern), take max → fuzzyScore, record bestPattern
   c. Keyword bonus: candidate.contains(definition.keywordSignal) → +0.15
   d. composite = min(1.0, max(exactScore, fuzzyScore) + keywordBonus)
3. Collect (definition, composite, bestMatchedPattern) tuples, sort descending by composite
4. Apply margin check: if len >= 2 and tuples[0].score - tuples[1].score < minimumMargin → return nil (ambiguous)
5. If top score < definition.confidenceThreshold → return nil
6. Return (tuples[0].definition, tuples[0].score) — caller also needs the matched pattern for span removal

**detect(transcript:modes:)** flow:
1. Trim original to trimmedOriginal
2. If trimmedOriginal is empty → return ConvertIntent(.passthrough, strippedBody: "", originalTranscript: transcript)
3. normalized = normalize(trimmedOriginal)
4. (leadingZone, trailingZone) = extractZones(from: normalized)
5. Score trailing zone → trailingWinner (optional)
6. Score leading zone → leadingWinner (optional)
7. If trailingWinner exists:
   a. Extract body by removing trailing command span from trimmedOriginal
   b. Apply stripLeadingTriggerIfPresent to the extracted body
   c. Return ConvertIntent(mode: trailingWinner.mode, strippedBody: body, originalTranscript: transcript)
8. If leadingWinner exists:
   a. Extract body by removing leading command span from trimmedOriginal
   b. Return ConvertIntent(mode: leadingWinner.mode, strippedBody: body, originalTranscript: transcript)
9. Passthrough: return ConvertIntent(.passthrough, strippedBody: trimmedOriginal, originalTranscript: transcript)

**Body extraction (span removal)**:

For trailing match:
- Find the matched pattern (the actual pattern string from IntentCatalog that scored highest) in the normalized trailing zone
- Do a case-insensitive range search for that pattern in trimmedOriginal, searching from the end (use .backwards option)
- If found: remove from that range to the end of the string (+ adjacent whitespace)
- Trim the result → strippedBody
- If not found (edge case — normalized form doesn't map back): fall back to using the trailing zone's token count to trim the right number of characters

For leading match:
- Case-insensitive range search from the beginning
- Remove from start to end of matched range + adjacent whitespace
- Trim → strippedBody

Edge case: if the entire transcript is the command → strippedBody = ""

**stripLeadingTriggerIfPresent(from body:)**:
Preserved from Phase 7 behavior. Iterate all IntentCatalog.all patterns. If normalized body starts with any pattern, strip it and return trimmed remainder. Return original body if no leading trigger found.
